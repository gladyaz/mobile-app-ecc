# UI design principle (product owner, 2026-08-12)

Refine the UI so it's more smooth and good for dummy user but keep the scope
just like what we're already doing.

In practice: every UI change should make interactions smoother and immediately
understandable to a first-time/non-technical user — visual hierarchy, spacing,
feedback, discoverability, consistency — without adding features or broadening
the approved scope of the slice being worked on.
